neon — Azure Deployment Architecture

Phase 5 · Container Apps + Static Web Apps · Azure DevOps CI/CD

Compute — Container Apps

  • • FastAPI on Azure Container Apps (Consumption plan)
  • • Min 1 replica — always warm, no cold starts
  • • Max 10 replicas — scales on HTTP concurrency
  • • Threshold: 20 concurrent requests per replica
  • • External HTTPS ingress on port 8000
  • • Image: neoncr.azurecr.io/neon-api:<build-id>

CI/CD — Azure DevOps

  • • backend.yml: test → build → push ACR → deploy
  • • frontend.yml: npm ci + build → Static Web Apps
  • • Images tagged with Build.BuildId + latest
  • • Secrets in ADO variable group (neon-secrets)
  • • Tests must pass before image build
  • • Post-deploy smoke: GET /health → 200

Security & Secrets

  • • API keys in Azure Key Vault (Standard tier)
  • • ALLOWED_ORIGINS set to SWA URL in production
  • • CORSMiddleware — configurable via env var
  • • Service principal for ADO → ACR / Container Apps
  • • Secrets never in source or pipeline logs
  • • Infra as code: infra/main.bicep
