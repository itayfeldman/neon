neon · Module Architecture

Quantitative finance library — options pricing & risk (Greeks)

Dependency Flow

  • • portfolio → instruments → greeks → datetime → core
  • • Dependencies point strictly downward — no upward imports
  • • Greeks receive market data via attribute injection (not constructor)
  • • OptionInputs is the canonical input struct for all options

Greeks Design

  • • Greeks base class: default identity values (delta=1, rest=0)
  • • AnalyticalGreeks: Black-Scholes closed-form (price, delta, gamma, vega, theta, rho)
  • • NumericalGreeks: central finite differences; accepts any pricing_fn callable
  • • vanna/volga: only NumericalGreeks has real implementations

Status & Conventions

  • • EuropeanOption: fully wired (delegates to injected Greeks)
  • • American / Asian / Bermuda: raise NotImplementedError
  • • OptionType & PositionDirection: IntEnum ±1 (multiply into formulas)
  • • DATE_FORMAT = "%Y%m%d" — e.g. "20260408"
